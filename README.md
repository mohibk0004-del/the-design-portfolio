# Mohib Khan, portfolio

React + Vite single page. Smooth scroll by Lenis, every section driven by scroll
progress (no animation library). See `DESIGN.md` for the system.

```sh
npm install
npm run dev     # local server
npm run build   # production build in dist/
npm run lint
```

Add your own photographs to `src/assets/photos/` to replace the placeholder tiles.
